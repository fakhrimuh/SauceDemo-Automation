# 🧪 SauceDemo Automation Testing

This project contains automated tests for the SauceDemo website, a demo environment designed for practicing QA automation skills. The purpose of this project is to validate key user flows such as login, product sorting, add-to-cart functionality, and checkout processes, ensuring that the application behaves as expected under various scenarios.

The automated tests cover both positive and negative cases, including form validation, navigation behavior, and error handling.

## 🎯 Objectives
- To practice implementing automated tests using modern QA tools.
- To ensure core functionalities of SauceDemo work correctly.
- To demonstrate practical skills in designing, executing, and maintaining automated test scripts.
- To provide clear and reusable test cases for common e-commerce workflows.

## 🛠️ Tools & Technologies
- **Automation Framework:** Cypress  
- **Language:** JavaScript 
- **Test Design:** Page Object Model (POM)
